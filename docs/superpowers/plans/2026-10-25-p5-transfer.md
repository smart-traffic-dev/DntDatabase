# P5 Transfer (Jobs, Import, Dump/Restore) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Long transfers run as jobs (progress, Stop, log, history, re-run); users import CSV/TSV/JSON/JSONL/XLSX with mapping, three modes and a dry run that never touches the target; users dump with the built-in dump or external tools and restore through exactly three guarded paths.

**Architecture:** `core::sql::stream` (N6) splits arbitrarily large SQL incrementally with `split`'s exact semantics. A new pure crate `dnt-transfer` holds readers, conversion, mapping, batching, dump rendering, restore detection and external-tool argument building. `src-tauri/src/jobs` (N5) runs jobs on dedicated sessions with a per-connection limit, `job://progress` events and SQLite persistence (MIGRATION_7). `src-tauri/src/import_data` and `src-tauri/src/backup` implement the import, dump, restore and N7 runners on top of plans + guard. The UI adds a Jobs panel, an import wizard and dump/restore dialogs.

**Tech Stack:** Rust (tokio incl. `process`, serde, specta, proptest, csv, calamine, flate2, sha2), Tauri 2 + tauri-specta, React 18 + TypeScript + Zustand, Vitest, Playwright (e2e-web).

**Spec:** `docs/superpowers/specs/2026-10-25-p5-transfer-design.md` (rulings R1–R36 are binding).

**Model per task:** each heading carries `[sonnet]` (mechanical, well specified) or `[opus]` (design judgement, engine semantics, concurrency, safety). Reviewers use the same model as the implementer. (R36: in this environment only the default model is reachable; the tags still record difficulty.)

## Review Focus

1. N6 equals `split` for any chunking (Task 1 proptest `stream_matches_split_for_any_chunking`) and is linear on a 64 MiB line (`long_line_is_linear`).
2. A job never sends a statement after Stop, and a queued job stopped before its slot never runs (Task 3 `stop_queued_job_never_runs`, `stop_between_batches_sends_nothing_more`).
3. The dry run never sends `INSERT`/`DELETE`/`TRUNCATE` to the target and does not advance a PG sequence (Task 10 fake-session test `dry_run_never_writes_target`; Task 11 DB test `dry_run_keeps_table_intact` incl. replace mode on MySQL and `pg_sequence_unchanged`).
4. MySQL replace-all with `TRUNCATE` or a non-transactional table is an irreversible pre-step that needs its own acknowledgement and (Production) the typed table name (Task 10 `irreversible_pre_step_needs_ack`).
5. Passwords never reach an external tool's arguments, environment values, the shown command line or the job log (Task 15 `secrets_never_in_args_env_or_log`).
6. A file changed after preview gives `PlanStale` with zero statements sent (Task 10 `changed_file_is_stale`, Task 16 `restore_changed_file_is_stale`).
7. A `pg_dump` plain file with `COPY … FROM stdin` is routed to psql, or refused with nothing executed when psql is missing (Task 16 `copy_file_needs_psql`).
8. Restore is blocked on read-only connections on all three paths (Task 16 `read_only_blocks_every_restore_path`).

**Interfaces (spec §5):**
- `pub struct SplitOptions { pub detect_client: bool, pub max_statement_bytes: usize }` with `Default` = `{ detect_client: false, max_statement_bytes: 256 * 1024 * 1024 }`
- `pub struct StreamStatement { pub text: String, pub start: u64, pub end: u64 }` (Debug, Clone, PartialEq, Eq)
- `pub enum SplitEvent { Statement(StreamStatement), CopyData { start: u64, end: u64 }, ClientCommand(StreamStatement) }`
- `pub enum SplitError { InvalidUtf8 { offset: u64 }, StatementTooLarge { start: u64, limit: usize } }` (thiserror, Display English)
- `impl StreamSplitter { pub fn new(Dialect, SplitOptions) -> Self; pub fn set_dialect(&mut self, Dialect); pub fn dialect(&self) -> Dialect; pub fn push(&mut self, &[u8]); pub fn finish(&mut self); pub fn next_event(&mut self) -> Result<Option<SplitEvent>, SplitError>; pub fn is_done(&self) -> bool; pub fn consumed(&self) -> u64 }`
- `pub fn is_copy_from_stdin(stmt: &str) -> bool` (tokens at depth 0 via `lexer::tokenize`: first word `COPY`, a later `FROM` immediately followed by word `STDIN`, case-insensitive; PG only — callers check the dialect)
- Helper for tests and callers: `pub fn split_all(input: &[u8], dialect: Dialect, opts: SplitOptions, chunk: usize) -> Result<Vec<SplitEvent>, SplitError>`

Implementation guidance: keep `buf: Vec<u8>` starting at the current segment start (`base: u64` absolute offset), `scan: usize` (next byte to look at), `prev_byte: Option<u8>` (byte before `buf[0]` in the stream), `line_blank: bool` (whether the bytes of the current line before `buf[0]` are all spaces/tabs), `delim: String`, `limit` = index of the last `\n` in `buf` (or `buf.len()` after `finish`). Port `split`'s loop: at `scan < limit` take the same decisions using a view that exposes `prev_byte` for `prev_is_ident` (simplest: keep one context byte at the front of the buffer and offset all indices by 1) and `line_blank` for `delimiter_directive`'s back-scan. When `skip_at` returns an end `>= buf.len()` and not finished, remember `retry_len = buf.len() * 2` and return `None` until the buffer reaches it (amortised). On a statement boundary build the `Statement` exactly like `split::push` (trim, `is_blank` with the current dialect, start = first non-blank byte), convert with `std::str::from_utf8` (error → `InvalidUtf8` with absolute offset), drain consumed bytes (keep the context byte), update `prev_byte`/`line_blank`. Detection per spec §5 rule 5. Do NOT change `split`.
