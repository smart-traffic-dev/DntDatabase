# F1 — `crates/ai`: FIM client, prompt and post-processing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pure, tested library that turns "editor text + cursor + schema" into a fill-in-the-middle request, sends it to any OpenAI-compatible `/completions` endpoint, and cleans the reply into a ghost-text suggestion. Nothing in `src-tauri` or `ui` changes; F2 wires it into the app, F3 into Monaco.

**Architecture:**
- `dnt-query` gains `redact_spans`, so the prompt builder knows where secrets are and can refuse to suggest inside one.
- New crate `crates/ai` (`dnt-ai`) with three modules:
  - `provider` — `FimClient` trait, `HttpFimClient` (reqwest + rustls/ring), `list_models`, error mapping;
  - `prompt` — redaction, cutting, schema header → `FimPrompt`;
  - `post` — cleans the model's text into the suggestion, and judges the Settings → Test probe.
- Cancellation is dropping the future (F2 keeps the `JoinHandle`/`AbortHandle`); the client holds no per-request state.

**Tech Stack:** Rust 1.99, tokio, reqwest 0.13 (`rustls-no-provider`), rustls 0.23 with the ring provider, rustls-platform-verifier, secrecy, thiserror, serde_json.

**Spec:** `docs/superpowers/specs/2026-11-04-ai-editor-completion-design.md` — §2, §3 (`crates/ai` part), §4, §5.3, §6.2 (probe judgement), §7 (error classes), §8, F1 in §11.

## Global Constraints

- **Only the OpenAI-compatible standard.** One request shape (`POST {base_url}/completions` with `suffix`) and `GET {base_url}/models`. No provider-specific code paths, names or detection.
- **No `src-tauri` or `ui` change.** Bindings do not change.
- **New dependencies are exactly:** `reqwest` (direct, already in the lock through Tauri), `rustls-platform-verifier` (already in the lock). Both go into `[workspace.dependencies]` with a comment. `reqwest` uses `default-features = false` and `features = ["rustls-no-provider", "json", "system-proxy"]`. **`cargo tree -i aws-lc-rs` must stay empty** and no `native-tls`/OpenSSL may appear (same rule as the drivers).
- **Secrets:** the API key is a `secrecy::SecretString`, sent only as `Authorization: Bearer …` with the header value marked sensitive; no type that holds it prints it in `Debug`. No prompt, suffix or reply text is ever passed to `tracing` (only lengths, status, elapsed ms, model).
- **No redirects** (`redirect::Policy::none()`): a 3xx is an error naming the target host.
- **Identifiers, error text and doc comments are in English.** Exact strings below are verbatim.
- **Byte vs UTF-16:** the editor speaks UTF-16 offsets; everything inside `dnt-ai` is byte offsets, converted once with `dnt_query::Utf16Map`. Every cut lands on a `char` boundary.
- **Verification per task:** `cargo check --workspace --all-targets`, the task's tests, `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`.
- **Commit style:** `feat(query): …` for Task 1, `feat(ai): …` for the rest; one commit per task.
- **Decisions this plan makes:**
  1. TLS: a rustls `ClientConfig` built with the ring provider and the platform verifier (Windows certificate store, so corporate CAs work), handed to reqwest as a preconfigured backend.
  2. Requests are not streamed (`stream: false`).
  3. `stop` is `["\n\n"]` only (spec §5.3).
  4. The cursor is "inside a secret" when `start < cursor <= end` of a redacted span: no suggestion right after a password literal either.
  5. The schema header uses `dnt_core::meta::ColumnBrief` (name + type); no keys.

## Review Focus

1. **`CREATE USER u IDENTIFIED BY 'hunt|` with the cursor at `|`.** No request is built (`Skip::InSecret`). Pinned by Task 4 test `cursor_in_secret_skips`.
2. **A document holding `ALTER USER u IDENTIFIED BY 'hunter2'` above the cursor.** The prompt contains `'[REDACTED]'`, never `hunter2`. Pinned by Task 4 test `prompt_never_contains_secrets`.
3. **A provider answering `302 Location: https://evil.example/`.** No second request is sent and the key goes nowhere else. Pinned by Task 3 test `redirect_is_not_followed`.
4. **A key-less local endpoint.** No `Authorization` header is sent at all. Pinned by Task 3 test `no_key_no_auth_header`.
5. **`Debug` of the client and endpoint config.** Never shows the key. Pinned by Task 2 test `endpoint_debug_hides_key`.

| 3xx | `Redirected { host }` (host of `Location`, or `"unknown"`) |

### Task 4: Prompt builder

**Files:**
- Create: `crates/ai/src/prompt.rs`

**Interfaces:**
- Produces:

```rust
pub struct TableBrief {
    pub schema: Option<String>,
    pub name: String,
    pub columns: Vec<dnt_core::meta::ColumnBrief>,
}
pub struct PromptInput<'a> {
    pub dialect: Dialect,
    pub server_version: Option<&'a str>,   // e.g. "PostgreSQL 16.4"; None → dialect name only
    pub database: Option<&'a str>,
    pub schema: Option<&'a str>,
    pub text: &'a str,                     // the whole editor document
    pub cursor_utf16: u32,                 // Monaco offset
    pub tables: &'a [TableBrief],          // the SchemaCache of `database`
}
pub struct FimPrompt {
    pub prompt: String,          // header + redacted prefix
    pub suffix: String,          // redacted suffix
    pub statement_head: String,  // redacted text of the current statement before the cursor (for post)
}
pub enum Skip { InSecret }
pub fn build(input: &PromptInput) -> Result<FimPrompt, Skip>;

pub const PREFIX_MAX: usize = 6 * 1024;
pub const SUFFIX_MAX: usize = 2 * 1024;
pub const HEADER_MAX: usize = 3 * 1024;
```

- **Redaction (spec §4.1):** split the document with `dnt_core::sql::split`; run `redact_spans` on every statement range **and on every gap between statements** (comments outside statements can hold secrets). If the byte cursor satisfies `start < cursor <= end` for any span → `Err(Skip::InSecret)`. Otherwise build the redacted document and the shifted cursor.
- **Current statement:** the split statement whose `[start, end]` contains the cursor; if none (cursor in a gap), the current statement starts at the end of the previous one (or 0).
- **Prefix:** redacted text before the cursor. If longer than `PREFIX_MAX`: start at the earliest statement start within the last `PREFIX_MAX` bytes; if the current statement alone is longer, cut at `cursor - PREFIX_MAX` rounded up to the next `char` boundary, then forward to the next line start.
- **Suffix:** redacted text after the cursor, at most `SUFFIX_MAX` bytes; when cut, cut back to the last `\n` inside the limit (if any).
- **Header (spec §4.2):** lines of SQL comments ending in `\n`:
  - `-- Dialect: <server_version or "MySQL" / "PostgreSQL">`
  - `-- Database: <db>` plus `, schema: <schema>` when set; omitted when no database.
  - `-- Tables:` then `--   <name>(<col> <type>, …)` for each table referenced in the current statement, in order of first reference. A table is referenced when a `Word` / quoted-identifier token of the statement (via `dnt_core::sql::tokenize`, quotes stripped) equals its name case-insensitively, or `schema.name` matches. Tables of another schema than `input.schema` are written `schema.name`.
  - `-- Other tables: a, b, …` with the remaining tables by name, at most 200 names, wrapped into lines of ≤ 100 chars each starting with `--   `.
  - Total header ≤ `HEADER_MAX`: a referenced table whose line does not fit is written with as many columns as fit plus `, …)`; other-table names stop when the next would not fit.
  - Every name and type has control characters (including `\r`, `\n`) replaced by a space, so nothing escapes the comment.
- `prompt = header + prefix`.

### Task 5: Post-processing and probe judgement

**Files:**
- Create: `crates/ai/src/post.rs`

**Interfaces:**
- Produces:

```rust
pub struct PostCtx<'a> {
    pub dialect: Dialect,
    pub statement_head: &'a str,   // FimPrompt::statement_head
    pub prefix_tail: &'a str,      // last ≤ 256 bytes of the prefix (repetition check)
    pub suffix: &'a str,
    pub max_lines: usize,          // default 8
}
pub fn clean(raw: &str, ctx: &PostCtx) -> Option<String>;

pub const PROBE_PROMPT: &str = "SELECT id, name\nFROM users\nWHERE ";
pub const PROBE_SUFFIX: &str = "\nORDER BY id;";
pub enum ProbeVerdict { Ok, IgnoresSuffix, Empty }
pub fn judge_probe(raw: &str) -> ProbeVerdict;
```

- **`clean`, in order (spec §5.3):**
  1. `\r\n` → `\n`.
  2. Cut at the first FIM control token: any of `<|fim_prefix|>`, `<|fim_suffix|>`, `<|fim_middle|>`, `<|fim_pad|>`, `<|endoftext|>`, `<|file_separator|>`, `<fim_prefix>`, `<fim_suffix>`, `<fim_middle>`, `<PRE>`, `<SUF>`, `<MID>`, `<EOT>`, `<｜fim▁begin｜>`, `<｜fim▁hole｜>`, `<｜fim▁end｜>`, `<｜end▁of▁sentence｜>`.
  3. Cut at the first blank line (`\n` followed by optional spaces/tabs and `\n`).
  4. Keep at most `max_lines` lines.
  5. Remove the longest tail of the text that equals a head of `suffix.trim_start()` (at least 1 char), then trim trailing spaces/tabs.
  6. Keep up to and including the first `;` that ends a statement: tokenize `statement_head + text` with the dialect and take the first `Punct(b';')` token starting at or after `statement_head.len()`.
  7. Return `None` if the result is empty or only whitespace, or if `prefix_tail.trim_end()` ends with `result.trim()` (the model repeated what is already there).
- **`judge_probe`:** after `clean` with the probe as context: `Empty` when `None`; `IgnoresSuffix` when the text contains `ORDER BY` (case-insensitive) or ends with `;`; otherwise `Ok`.
