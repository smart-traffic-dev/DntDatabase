# DntDatabase P1 — Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ứng dụng desktop Windows (Rust + Tauri 2 + React/TS) quản lý connection MySQL/MariaDB/PostgreSQL, kết nối qua SSH/TLS, duyệt schema, export/import connection (`.dntconn`, Navicat `.ncx`).

**Architecture:** Cargo workspace gồm các crate `dnt-core` (kiểu + trait), `dnt-driver-mysql`, `dnt-driver-pg`, `dnt-tunnel`, `dnt-store` (SQLite, keyring, file format) và `dnt-testkit`. App shell `src-tauri` giữ `SessionManager` và expose Tauri commands có kiểu sinh bằng `tauri-specta`. Frontend `ui/` dùng React + Zustand, chỉ gọi backend qua `ui/src/api/`.

**Tech Stack:** Rust stable (MSVC), Tauri 2, tokio, mysql_async (rustls), tokio-postgres + tokio-postgres-rustls, rustls 0.23, russh, rusqlite (bundled) + rusqlite_migration, keyring 3 (`windows-native`), argon2, chacha20poly1305, aes + cbc, quick-xml, secrecy, zeroize, thiserror, async-trait, tracing + tracing-appender, insta, specta + tauri-specta. Frontend: pnpm, React 18, TypeScript, Vite, Zustand, @tanstack/react-virtual, @fontsource (IBM Plex Sans, JetBrains Mono), Vitest + Testing Library. E2E: tauri-driver + WebdriverIO.

**Spec:** `docs/superpowers/specs/2026-10-19-p1-core-design.md`. **Canvas UI:** https://claude.ai/artifact/7Uh7EGUTkNvKgBXUWcBB3B

## Global Constraints

- Nền tảng đích P1: Windows 10/11 x64. Code không dùng thư viện C ngoài SQLite bundled. Keychain đi qua trait `SecretStore`.
- Biến thể được hỗ trợ: MySQL 5.7, MySQL 8.x, MariaDB 10.3+, PostgreSQL 12–17.
- Bundle identifier `com.dnt.dntdatabase`, product name `DntDatabase`. Dữ liệu app tại `%APPDATA%\DntDatabase\` (`app.db`, `known_hosts`, `logs\`).
- Secret không bao giờ nằm trong SQLite, log hay payload gửi lên frontend. Mọi secret trong RAM là `secrecy::SecretString`.
- Key trong keychain: `DntDatabase/<conn_uuid>/{db_password|ssh_password|ssh_key_passphrase}`.
- Mặc định `ExecOptions`: `max_rows = 10_000`, `batch_size = 500`. Timeout kết nối SSH và DB mỗi loại 10 giây. Keepalive SSH 30 giây.
- Số nguyên có |x| > 2⁵³ (9_007_199_254_740_992) được gửi lên UI dạng string. `Bytes.preview` tối đa 64 byte.
- `.dntconn` dùng Argon2id `m=65536, t=3, p=1` và XChaCha20-Poly1305. Passphrase tối thiểu 8 ký tự.
- Log mặc định ở mức `info`, không ghi nội dung SQL. Log xoay theo ngày, giữ 7 ngày.
- UI tiếng Anh, theme sáng, token màu lấy từ canvas (§Task 17).
- Mỗi task kết thúc bằng `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings` xanh (task UI: `pnpm --dir ui lint && pnpm --dir ui test` xanh) rồi mới commit.
- Integration test chỉ chạy khi `DNT_TEST_DB=1`. Nếu không có biến này, test gọi `dnt_testkit::require_db!()` sẽ return sớm và in `skipped`.
- **Điều kiện tiên quyết** (người dùng tự cài): rustup (stable-x86_64-pc-windows-msvc), Visual Studio Build Tools (C++), Node 22, pnpm, Docker Desktop, WebView2.

## Review Focus

1. **Dữ liệu và định danh có Unicode hoặc ký tự đặc biệt.** Bảng tên `đơn_hàng`, cột tên ``we`ird"col``, dữ liệu tiếng Việt utf8mb4 phải liệt kê, ra DDL và đọc ngược về `Value::Text` đúng. Test nằm trong fixture và snapshot của Task 11 và Task 13.
2. **Database rất lớn (5.000 bảng).** `list_objects(Table)` trên MySQL 8 và PG 17 phải trả về trong dưới 2 giây, và cây UI phải ảo hóa. Test `lists_5000_tables_fast` (Task 11, Task 13) và test ảo hóa (Task 17).
3. **Giá trị "zero date" của MySQL 5.7/MariaDB** (`0000-00-00 00:00:00`, `2024-00-10`) không được gây lỗi; chúng hiển thị thành `Value::DateTime("0000-00-00 00:00:00")`. Test `zero_dates_do_not_fail` (Task 10).
4. **User thiếu quyền.** Với user `dnt_limited` chỉ có SELECT trên một bảng, cây vẫn hiện những gì user thấy được. `object_ddl` trên object không có quyền trả `DbError::Server`, không panic. Test `limited_user_sees_partial_tree` (Task 11, Task 13).
5. **Key SSH có vấn đề.** Đường dẫn key không tồn tại, hoặc passphrase sai/thiếu, phải trả `DbError::Config { field: Some("ssh.key_path") }` hoặc `Ssh { stage: Auth }` kèm gợi ý passphrase, không treo. Test `missing_key_file_is_config_error` và `wrong_key_passphrase_is_auth_error` (Task 14).
