# DntDatabase P3 — Dữ liệu an toàn — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lọc phía server, sửa/thêm/xóa dòng có chống xung đột, xem/sửa giá trị lớn, Copy as và Manual commit trên Data tab và query tab, với mọi câu ghi đi qua plan bất biến và guard ở backend, trên MySQL 5.7/8.x, MariaDB 10.6/11.4 và PostgreSQL 12/17.

**Architecture:** `core` có thêm `FullValue`/`CellMode` (giá trị đầy đủ, tách khỏi `Value` hiển thị) và `sql::build` (literal + DML/SELECT theo dialect). `dnt-query` có thêm `edit` (EditSet → EditPlan thuần: khóa, `RowGuard`, `atomic`, verdict) và các cờ rủi ro còn thiếu. `src-tauri` lưu edit plan bất biến (giống `PlanStore` của query), chạy Apply trên session riêng, giữ `outcome_unknown` tới UI và History. UI thêm FilterBar, lưới sửa được có stage/preview/apply, value editor, Copy as, công tắc Manual commit.

**Tech Stack:** Rust stable (MSVC), Tauri 2, tokio, tauri-specta `=2.0.0-rc.21`, rusqlite, `mysql_async`, `tokio-postgres`. UI: React 19, TypeScript, Zustand, Vitest, `@glideapps/glide-data-grid`. E2E: Playwright (`e2e-web`), tauri-driver (`e2e`).

**Spec:** `docs/superpowers/specs/2026-10-20-core-roadmap-p3-p6-design.md` bản 2 (binding): §2, §4.0–§4.3, §5, §9. Hợp đồng chung: `2026-10-19-p1-core-design.md`, `2026-10-19-p2-query-design.md`.

**Branch:** `feat/p3-data`, cắt từ `main` **sau khi** việc dọn branch đang chạy song song đã xong. Plan viết trên `main` tại `52b7978`; Task 0 kiểm tra lại các giả định.

**Interfaces:**
- Consumes: `FullValue` (Task 1), `Dialect`, `MySqlMode`, `LogicalType`.
- Produces:
  ```rust
  #[derive(Debug, Clone, PartialEq, Eq)]
  pub struct ColumnTarget { pub name: String, pub db_type: String, pub logical: LogicalType, pub collation: Option<String> }
  #[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
  pub enum BuildError { #[error("unsupported value for {column} ({db_type})")] Unsupported { column: String, db_type: String },
  ```

- Quy tắc (spec §4.1): NULL → `NULL`. MySQL chuỗi: thoát `\`→`\\`, `'`→`\'`, NUL→`\0` trừ khi `no_backslash_escapes` (khi đó chỉ `'`→`''`, NUL → `Invalid`); prefix `_utf8mb4`. Số: Int/UInt/Decimal in thẳng (Decimal phải khớp `^-?\d+(\.\d+)?([eE][-+]?\d+)?$`, sai → `Invalid`); Float: NaN/±Inf → PG `'NaN'::float8`…, MySQL `Invalid`. Bool: MySQL `1`/`0`, PG `TRUE`/`FALSE`. Binary: MySQL `X'..'`, PG `'\x..'::bytea`. PG kiểu không phải text/số/bool: `'…'::<db_type>` (db_type đã chuẩn hóa từ introspection). Json MySQL: `CAST(_utf8mb4'…' AS JSON)`. Kiểu `Other`/spatial/range/composite → `Unsupported`.

**Files:**
- Modify: `crates/core/src/sql/build.rs`, `crates/core/src/sql/ident.rs` (`select_page_sql` gọi qua `select_sql`, giữ tên cũ làm wrapper để không vỡ caller)

**Interfaces:**
- Consumes: `literal`, `ColumnTarget`, `BuildError` (Task 3); `quote_ident`, `qualified_name`.
- Produces:
  ```rust
  pub struct TableRef { pub kind: DbKind, pub database: String, pub schema: Option<String>, pub name: String }
  impl TableRef { pub fn relation(&self) -> String }            // = qualified_name(..)
  pub struct RowKey(pub Vec<(ColumnTarget, FullValue)>);         // không rỗng; không có giá trị NULL
  pub enum RowGuard { PgXmin(String), Snapshot(Vec<(ColumnTarget, FullValue)>), KeyOnly }
  #[derive(Serialize, Deserialize, specta::Type)] pub enum FilterOp { Eq, Ne, Lt, Le, Gt, Ge, Contains, StartsWith, EndsWith, IsNull, IsNotNull, In, Between }
  #[derive(Serialize, Deserialize, specta::Type)] pub struct FilterCond { pub column: String, pub op: FilterOp, pub values: Vec<Value>, pub case_insensitive: bool }
  #[derive(Serialize, Deserialize, specta::Type)] pub enum FilterJoin { And, Or }
  #[derive(Serialize, Deserialize, specta::Type)] #[serde(tag = "mode")] pub enum Filter { Conditions { join: FilterJoin, conds: Vec<FilterCond> }, Raw { where_sql: String } }
  pub struct Page { pub limit: u64, pub offset: u64 }
  pub fn select_sql(t: &TableRef, extra_cols: &[String], filter: Option<&Filter>, cols: &[ColumnTarget], order: &[(String, bool)], page: Page, d: Dialect) -> Result<String, BuildError>;
  pub fn count_filtered_sql(t: &TableRef, filter: Option<&Filter>, cols: &[ColumnTarget], d: Dialect) -> Result<String, BuildError>;
  pub fn insert_sql(t: &TableRef, cols: &[ColumnTarget], rows: &[Vec<FullValue>], returning: &[ColumnTarget], d: Dialect) -> Result<String, BuildError>;
  pub fn update_sql(t: &TableRef, key: &RowKey, set: &[(ColumnTarget, FullValue)], guard: &RowGuard, d: Dialect) -> Result<String, BuildError>;
  pub fn delete_sql(t: &TableRef, key: &RowKey, guard: &RowGuard, d: Dialect) -> Result<String, BuildError>;
  pub fn check_raw_where(where_sql: &str, d: Dialect) -> Result<(), BuildError>;
  ```
- Quy tắc:
  - `extra_cols` là biểu thức do backend chọn (chỉ `xmin::text` và tên cột khóa ẩn đã quote); đặt **trước** `*`: `SELECT xmin::text, * FROM …`.
